SMART POT

Smart Pot is an experimental hardware project designed to make taking care of plants easier.

The project explores ways technology can help monitor and care for a plant while keeping the system simple and practical.

PROJECT GOALS

  • Make plant care easier
  • Monitor plant conditions
  • Experiment with hardware
  • Develop an automated plant-care system

CURRENT STATUS

Smart Pot is currently an experimental project. More details will be documented as development continues.
